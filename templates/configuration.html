How Email Parsing Works
AI-Powered Parsing
Each incoming email is sent to Claude Haiku along with the configured prompt for that inbox type. Claude reads the email content and determines whether it is a daily backup status report or something to ignore — such as a monthly summary, a licence warning, or a marketing email.

For daily status emails, Claude extracts structured data for each server: the server name, whether the backup was successful or unsuccessful, and the timestamp from the backup column. This structured data is saved to the database.

If Claude is unavailable or the API call fails for any reason, the system automatically falls back to the built-in regex parser, so monitoring continues uninterrupted.
Regex Fallback
The regex parser acts as a safety net if the AI is unavailable. For server emails it looks for lines in the format:
ServerName (ServerID) Success/Failed Date Time

For NAS emails it determines status from the subject line and extracts the device name and timestamp using pattern matching.
